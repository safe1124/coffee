# 1년 커피값 시뮬레이터

Next.js App Router + TypeScript로 만든 커피 비용 비교 웹앱입니다.

## 기본 계산 기준

- 최종 음료량: 250ml (얼음 제외)
- 하루 3잔
- 연 365일
- 병커피: 500ml 1,000원 → 250ml당 500원
- 캡슐: 1잔 700원 / 머신 150,000원
- 에스프레소: 원두 20g 기준 1잔 600원 / 머신 400,000원
- 브루잉 484: 원두 20g 기준 1잔 600원 / 장비 10,000원

모든 가격은 웹 화면에서 직접 변경할 수 있으며 결과가 즉시 다시 계산됩니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 열면 됩니다.

## 포함 기능

- 하루 음용 잔수 변경
- 연간 음용 일수 변경
- 방식별 1잔 재료비 변경
- 방식별 장비비 변경
- 1년 재료비 및 총비용 자동 계산
- 실질 1잔 가격 계산
- 비용 순위 자동 정렬
- 비교 막대 그래프
- 모바일 반응형 UI

> 물값, 전기료, 세척제, 수리비, 종이필터 등 부대비용은 기본 계산에서 제외합니다.
